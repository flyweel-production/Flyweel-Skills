# Report templates

Replace "result" with the user's own result: lead, booked call, deal. Leave out rows the data cannot fill, and say which were left out.

## Weekly summary

```
## Week of [DATE]: ad performance

### Headline
[One sentence: the single most important thing]

### Key numbers (against prior week)
| | This week | Last week | Change |
|---|---|---|---|
| Spend | | | |
| Results | | | |
| Cost per result | | | |
| Click rate | | | |

### By channel
| | Google | Meta | Other | Total |
|---|---|---|---|---|
| Spend | | | | |
| Results | | | | |
| Cost per result | | | | |

### Top 3 campaigns by results
1. [Name]: [X] results at [cost] each

### Watch list
- [Campaign or issue that needs attention]

### Do next
1. [Action]. Expected effect: [outcome]
```

## Monthly review

```
## [MONTH]: ad performance review

### Summary
[3-4 sentences: what the spend returned, what worked, what did not, what changes]

### Plan against actual
| Channel | Planned | Actual | Difference |
|---|---|---|---|

### Scorecard
| Measure | Target | Actual | Status |
|---|---|---|---|
| Cost per result | | | |
| Results | | | |
| Revenue landed (if known) | | | |
| Return on spend (if known) | | | |

### Weekly trend
[Four or five weeks, showing direction]

### Campaign tiers
Scale (cost steady, room to grow): [campaigns]
Hold (on target): [campaigns]
Fix (over target, improving): [campaigns]
Stop (over target, not improving): [campaigns]

### Still open
[Weeks whose leads have not had time to close. Not counted as a poor return.]

### Next month
- Budget: [amount] ([change] against this month)
- Actions: [2-3 specific changes]
- Tests: [1-2, each with what it should prove]
```
